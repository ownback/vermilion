One step is left: the Allow click

  1. Open System Settings > Privacy & Security and scroll to Security.
  2. Next to the message about blocked system software, click Allow and enter your password.
  3. Restart when macOS asks, and do not log in for about 3 minutes.

Until you do, the VermilionAccel kext does not load and the Mac stays on the basic display. Click Allow again after every update that changes this kext. If the firmware download failed during the install, run vermilion-firmware as root once you have a network connection.

The install log, with the rollback folder and any warning, is in /var/log/install.log.
