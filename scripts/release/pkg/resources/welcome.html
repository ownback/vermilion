Vermilion: experimental preview

A driver for the AMD Radeon RX 7900 XTX on macOS Tahoe 26.7.1 (build 25G241), for the PC it was written on. Use it only if you can recover a Mac that does not boot to a picture.

This installer needs the OpenCore part of the same release (Vermilion-<version>-OpenCore.zip) and installs only in macOS: it never writes the system volume or the EFI partition, and its only NVRAM write is the variable phxfb-squat. It downloads AMD's firmware from linux-firmware while it installs (no firmware is inside this package) and keeps a copy of every file it replaces.

This package is not signed with an Apple Developer ID. Check it against SHA256SUMS from the release page. To remove everything later, run vermilion-uninstall as root in Terminal.
